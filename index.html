Gameplay, Scoring & Levels

T-03

Block Blitz is an 8×8 grid block puzzle game. You drag blocks from a tray of up to 3 visible blocks onto the board. When a full row or column is filled, it is cleared and you earn points. The game ends when no block from the current tray can be placed anywhere on the board.

Tray: Up to 3 blocks are shown at a time (from a pool of 5). A new set is generated when all 3 are used.

Scoring System (from source code):

ActionPoints
Place a block on the board+0
Clear 1 line (row or column)+100
Clear 2 lines simultaneously+250
Clear 3 lines simultaneously+400
Clear 4+ lines simultaneously+600 (+100 per extra line)
Combo bonus (per consecutive combo)+50 × combo count

Level Multipliers: Each level applies a score multiplier. Higher levels reward more points per action.
